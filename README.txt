BS2 Android project

Сборка APK через телефон:
1. Распакуй архив.
2. Создай новый репозиторий на https://github.com/new
3. Загрузи в репозиторий ВСЕ файлы и папки из этой папки (включая .github).
4. Открой вкладку Actions в репозитории.
5. Выбери "Build BS2 APK" и нажми "Run workflow".
6. Дождись зелёного статуса сборки.
7. Открой завершённый запуск и скачай артефакт "BS2-APK".
8. Распакуй скачанный архив и установи app-debug.apk.

Важно:
- Для сборки нужен интернет.
- Игра использует Three.js с CDN, поэтому для запуска игры тоже нужен интернет.
- Это debug APK для личной установки, не опубликованный Play Store релиз.
